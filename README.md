## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production (GitHub Pages base path: /portfolio/)
npm run build

# Preview production build
npm run preview
```

## Deployment

The site automatically deploys to GitHub Pages when changes are pushed to the `main` branch via GitHub Actions.

`public/robots.txt`, `public/sitemap.xml`, `public/projects.html`, and `public/og-image.png` are copied into `dist/` so GitHub Pages can serve them at `/portfolio/`.
